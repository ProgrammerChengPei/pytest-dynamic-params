# TalkTree 快照管理技能

## 职责

- 💾 **快照保存** - 保存整个对话的完整状态
- 🔄 **快照恢复** - 恢复到指定快照状态
- 📋 **快照列表** - 列出所有快照
- 🔍 **快照详情** - 查看快照内容
- 🗑️ **快照删除** - 删除指定快照
- 📤 **快照导出** - 导出快照到文件
- 📥 **快照导入** - 从文件导入快照
- 🔬 **快照比较** - 比较不同快照的差异

## 快照作用范围

**重要**：快照保存的是**整个对话**的所有话题，而不是单个话题。

**包含内容**：
- ✅ 所有话题及其问答对
- ✅ 所有记忆状态
- ✅ 话题树结构
- ✅ 上下文信息

## 命令定义

### tt snap ls

**功能**：列出所有快照

**语法**：
```bash
tt snap ls [参数]
```

**参数**（参考 git log 风格）：
- 必须使用 git log 风格（`-5`、`--grep "xxx"` 等）
- AI 应理解等价形式：`-5`、`-n 5`、`--limit 5`；`--grep`、`-g`
- 参数可以组合使用


**AI 应实现**：
1. 智能解析参数
2. 按参数执行
3. 构建树状结构
4. 显示树状图

**输出格式**：
```
**快照列表**
📍 当前：conv_{id}: {name}
📊 共 {count} 个快照

📁 conv_{id}: {name}
├── snap_{id}: {name}
│   ├── topic_{id}: {name}
│   │   └── qa_{id} | {问题摘要}
```

### tt snap save

**功能**：保存快照

**语法**：
```bash
tt snap save <name>
```

**AI 应实现**：
1. 生成快照 ID（`snap_{uuid}`）
2. 创建快照对象（保存整个对话）
3. 保存所有话题的状态
4. 添加到对话的快照列表
5. 保存快照到文件
6. 保存对话主文件

**输出格式**：
```
✅ 已保存快照
💾 snap_{id}: {name} | conv_{id}
```

### tt snap use

**功能**：使用快照（恢复状态）

**语法**：
```bash
tt snap use <snap_id_or_name> [新问题]
```

**AI 应实现**：
1. 查找快照
2. 保存当前状态（用于回滚）
3. 恢复快照状态（整个对话）
4. 如果有新问题，基于恢复的状态回答
5. 保存

**输出格式**：
```
✅ 已恢复快照并回答
📎 snap_{id}: {name} | conv_{id}
💾 conv_{id}/topic_{id}/qa_{id} | {问题}
```

### tt snap show

**功能**：显示快照详情

**语法**：
```bash
tt snap show <snap_id_or_name>
```

**AI 应实现**：
1. 查找快照
2. 显示快照中的所有话题和问答

**输出格式**：
```
**快照详情**
📎 snap_{id}: {name} | conv_{id}

├── topic_{id}: {name}
│   └── qa_{id} | {问题摘要}
```

### tt snap rm

**功能**：删除快照

**语法**：
```bash
tt snap rm <snap_id_or_name>
```

**特殊用法**：
- 使用 `.` 删除所有快照

**AI 应实现**：
1. 查找快照
2. 从列表中移除
3. 保存

### tt snap diff

**功能**：比较两个快照的差异

**语法**：
```bash
tt snap diff <snap1> <snap2>
```

**AI 应实现**：
1. 查找两个快照
2. 比较话题数、问答数
3. 找出新增和删除的话题
4. 生成对比报告

### tt snap export

**功能**：导出快照到文件

**语法**：
```bash
tt snap export <snap_id> [file_path]
```

**AI 应实现**：
1. 查找快照
2. 序列化快照
3. 写入文件

### tt snap import

**功能**：从文件导入快照

**语法**：
```bash
tt snap import <file_path>
```

**AI 应实现**：
1. 读取文件
2. 验证格式
3. 创建快照对象
4. 添加到对话
5. 保存

## 协作关系

- 调用 **persistence** - 保存快照到文件
- 被 **context-navigator** 调用 - 提供快照管理
- 调用 **topic-manager** - 恢复话题状态
