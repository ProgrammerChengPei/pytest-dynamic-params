# TalkTree 上下文导航技能

## 职责

- 🧭 **话题导航** - 在不同话题间灵活切换
- 📜 **历史浏览** - 浏览和跳转到历史问答对
- 💾 **快照管理** - 保存和恢复上下文快照
- 🔗 **记忆继承** - 管理话题间的记忆继承
- 🌳 **话题树维护** - 维护话题层级结构

## 命令定义

### tt topic new

**功能**：创建新话题

**语法**：
```bash
tt topic new <name> [-p <parent>]
```

**AI 应实现**：
1. 验证话题名称不重复
2. 生成唯一 ID（`topic_{uuid}`）
3. 建立父子关系
4. 继承父话题记忆（根据继承策略）
5. 保存到文件
6. 返回话题信息

**输出格式**：
```
✅ 已创建新话题
💾 topic_{id}: {name} | {qa_count}问答
```

### tt topic ls

**功能**：列出所有话题

**语法**：
```bash
tt topic ls [参数...]
```

**参数**（参考 git log 风格）：
- 必须使用 git log 风格（`-5`、`--grep "xxx"` 等）
- AI 应理解等价形式：`-5`、`-n 5`、`--limit 5`；`--grep`、`-g`
- 参数可以组合使用

**AI 应实现**：
1. 智能解析参数
2. 按参数执行
3. 构建树状结构
4. 显示树状图

**输出格式**：
```
**话题列表**
📍 当前：topic_{id}: {name} | {qa_count}问答
📊 共 {count} 个话题

📁 topic_{id}: {name}
    ├── qa_{id} | {问题摘要}
    └── ... 还有 {count} 轮
```

### tt topic use

**功能**：切换到指定话题

**语法**：
```bash
tt topic use <name_or_id>
```

**AI 应实现**：
1. 查找话题
2. 保存当前话题状态
3. 加载新话题上下文
4. 记录状态变更
5. 保存到文件

**输出格式**：
```
✅ 已切换到话题
📎 topic_{id}: {name} | {qa_count}问答
```

### tt topic rm

**功能**：删除话题

**语法**：
```bash
tt topic rm <name_or_id>
```

**AI 应实现**：
1. 检查话题存在且非激活状态
2. 递归删除子话题
3. 从父话题移除
4. 记录变更
5. 保存到文件

### tt topic merge

**功能**：合并两个话题

**语法**：
```bash
tt topic merge <topic1> <topic2>
```

**AI 应实现**：
1. 迁移问答对
2. 合并记忆
3. 迁移子话题
4. 删除源话题
5. 保存

### tt snap ls

**功能**：列出所有快照

**语法**：
```bash
tt snap ls [参数]
```

**参数**（参考 git log 风格，AI 灵活理解）：
- 数字参数：限制显示数量
- 关键词过滤：按快照名称过滤
- 组合使用

**AI 应实现**：
1. 按关键词过滤
2. 限制数量
3. 显示快照及其话题和问答（树状图）

**输出格式**：
```
**快照列表**
📍 当前：conv_{id}: {name}
📊 共 {count} 个快照

📁 conv_{id}: {name}
├── snap_{id}: {name}
│   ├── topic_{id}: {name}
│   │   └── qa_{id} | {问题摘要}
```

### tt snap save

**功能**：保存快照

**语法**：
```bash
tt snap save <name>
```

**AI 应实现**：
1. 生成快照 ID（`snap_{uuid}`）
2. 保存整个对话的状态（所有话题、问答、记忆）
3. 添加到快照列表
4. 保存到文件

**输出格式**：
```
✅ 已保存快照
💾 snap_{id}: {name} | conv_{id}
```

### tt snap use

**功能**：使用快照（恢复状态）

**语法**：
```bash
tt snap use <snap_id_or_name> [新问题]
```

**AI 应实现**：
1. 查找快照
2. 保存当前状态（用于回滚）
3. 恢复快照状态
4. 如果有新问题，基于恢复的状态回答
5. 保存

**输出格式**：
```
✅ 已恢复快照并回答
📎 snap_{id}: {name} | conv_{id}
💾 conv_{id}/topic_{id}/qa_{id} | {问题}
```

### tt snap rm

**功能**：删除快照

**语法**：
```bash
tt snap rm <snap_id_or_name>
```

**特殊用法**：
- 使用 `.` 删除所有快照

**AI 应实现**：
1. 查找快照
2. 从列表中移除
3. 保存

## 协作关系

- 调用 **persistence** - 保存话题和快照到文件
- 调用 **topic-manager** - 管理话题树
- 调用 **memory-manager** - 实现记忆继承
- 调用 **qa-manager** - 提供历史导航
