# 更新文档 - 项目配置

## 项目文档路径

- 需求：`specs/需求.md`
- 架构设计：`specs/架构设计.md`
- 详细设计：`specs/详细设计.md`
- 用户文档：`docs/`
- 示例代码：`examples/`
- 项目文件：根目录下的部分文件

## 技能协作

- **使用** **`follow-up-check`** **技能**：判断是否需要更新文档
- **使用** **`code-review`** **技能**：确保文档与代码的一致性
- **使用** **`git-commit`** **技能**：生成提交信息和更新 CHANGELOG
