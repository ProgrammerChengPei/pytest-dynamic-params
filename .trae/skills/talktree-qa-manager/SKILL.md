# TalkTree 问答对管理技能

## 职责

- 💬 **问答对管理** - 列出、查看、删除问答对
- 🔍 **历史搜索** - 搜索包含关键词的问答
- 🎯 **精确导航** - 跳转到指定问答对
- 🔄 **接续对话** - 基于历史问答继续对话

## 命令定义

### tt qa ls

**功能**：列出当前话题的问答对

**语法**：
```bash
tt qa ls [参数]
```

**参数**（参考 git log 风格）：
- 必须使用 git log 风格（`-5`、`--grep "xxx"` 等）
- AI 应理解等价形式：`-5`、`-n 5`、`--limit 5`；`--grep`、`-g`
- 参数可以组合使用


**AI 应实现**：
1. 智能解析参数
2. 按参数执行
3. 构建树状结构
4. 显示树状图

**输出格式**：
```
**问答对列表**
📍 当前：topic_{id}: {name}
📊 共 {count} 条

├── qa_{id}: {问题摘要}
│   └── AI: {回答摘要}
```

### tt qa use

**功能**：切换到问答对（激活上下文并提问）

**语法**：
```bash
tt qa use <qa_id> [新问题]
```

**AI 应实现**：
1. 查找问答对
2. 激活该问答对的上下文
3. 如果有新问题，基于该上下文回答
4. 添加新问答对

**输出格式**：
```
✅ 已切换到问答对并回答
📎 conv_{id}/topic_{id}/qa_{id} | {摘要}
💾 conv_{id}/topic_{id}/qa_{id} | {问题}
```

### tt qa rm

**功能**：删除问答对

**语法**：
```bash
tt qa rm <qa_id>
```

**AI 应实现**：
1. 查找问答对
2. 从话题中移除
3. 更新元数据
4. 保存

### tt qa merge

**功能**：合并两个问答对

**语法**：
```bash
tt qa merge <qa1> <qa2>
```

**AI 应实现**：
1. 合并内容
2. 创建新问答对
3. 删除原问答对
4. 保存

## 协作关系

- 调用 **persistence** - 保存问答对到文件
- 被 **context-navigator** 调用 - 提供历史导航
- 调用 **topic-manager** - 管理话题内的问答
