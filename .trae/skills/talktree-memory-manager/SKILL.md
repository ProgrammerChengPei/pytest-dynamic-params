# TalkTree 记忆管理技能

## 职责

- 💾 **记忆存储** - 添加、删除、更新记忆
- 🔍 **记忆查询** - 列出、搜索记忆
- 🔗 **记忆继承** - 管理话题间的记忆继承
- 📤 **记忆导出** - 导出记忆到文件
- 📥 **记忆导入** - 从其他对话导入记忆

## 记忆类型

| 类型 | 说明 | 可继承 | 示例 |
|------|------|--------|------|
| `core_concept` | 核心概念 | ✅ | 装饰器的定义 |
| `fact` | 事实知识 | ✅ | Python 是解释型语言 |
| `preference` | 用户偏好 | ✅ | 喜欢简洁的代码风格 |
| `working_state` | 工作状态 | ❌ | 当前讨论的子话题 |
| `temp_context` | 临时上下文 | ❌ | 刚提到的变量名 |

## 命令定义

### tt mem ls

**功能**：查看记忆

**语法**：
```bash
tt mem ls [参数]
```

**参数**（参考 git log 风格）：
- 必须使用 git log 风格（`-5`、`--grep "xxx"` 等）
- AI 应理解等价形式：`-5`、`-n 5`、`--limit 5`；`--grep`、`-g`
- 参数可以组合使用

**AI 应实现**：
1. 智能解析参数
2. 按参数执行
3. 构建树状结构
4. 显示树状图

**输出格式**：
```
**记忆列表**
📍 当前：topic_{id}: {name}
📊 共 {count} 个记忆

├── 核心概念 (count)
│   └── {key}: {value}
│       └── 类型：{type} | 可继承：✅/❌
```

### tt mem add

**功能**：添加记忆

**语法**：
```bash
tt mem add <key> <value> [--type <type>] [--no-inherit]
```

**AI 应实现**：
1. 确定记忆类型
2. 生成记忆键
3. 设置继承属性
4. 添加到话题记忆
5. 保存

**输出格式**：
```
✅ 已添加记忆
💾 mem_{key}: {value} | {count}键值对 | conv_{id}
```

### tt mem rm

**功能**：删除记忆

**语法**：
```bash
tt mem rm <key>
```

**特殊用法**：
- 使用 `.` 删除所有记忆

**AI 应实现**：
1. 查找记忆
2. 删除记忆
3. 更新元数据
4. 保存

### tt mem save

**功能**：保存记忆状态到系统

**语法**：
```bash
tt mem save <name>
```

**AI 应实现**：
1. 创建记忆集合对象
2. 添加到对话的记忆集合列表
3. 保存

### tt mem use

**功能**：使用记忆（可附带新问题）

**语法**：
```bash
tt mem use <mem_id> [新问题]
```

**AI 应实现**：
1. 查找记忆集合
2. 激活记忆上下文
3. 如果有新问题，基于记忆回答
4. 添加新问答对

### tt mem export

**功能**：导出记忆到文件（备份/分享）

**语法**：
```bash
tt mem export <mem_id> [file_path]
```

**AI 应实现**：
1. 查找记忆集合
2. 序列化记忆
3. 写入文件

### tt mem import

**功能**：从其他对话导入记忆（复制语义）

**语法**：
```bash
tt mem import <mem_id> [-k <new_key>]
```

**AI 应实现**：
1. 查找记忆集合（跨对话）
2. 复制记忆（创建独立副本）
3. 添加到当前话题
4. 保存

## 记忆继承规则

**继承策略**（在配置文件中设置）：

| 策略 | 说明 | 继承内容 |
|------|------|---------|
| `default` | 默认 | 继承 core_concept、fact、preference |
| `all` | 全部 | 继承所有记忆（除 working_state） |
| `selective` | 选择性 | 仅继承 inheritable=true 的记忆 |
| `none` | 不继承 | 不继承任何记忆 |

## 协作关系

- 调用 **persistence** - 保存记忆到文件
- 被 **topic-manager** 调用 - 实现记忆继承
- 被 **context-navigator** 调用 - 提供记忆操作
- 被 **conversation-manager** 调用 - 跨对话记忆管理
