# TalkTree 命令规则

## 职责范围

本规则定义所有 TalkTree 命令的通用参数规则，避免在每个文件中重复说明。

## 通用参数规则

### ls 命令参数（参考 git log 风格）

所有 `ls` 命令都应遵循 git log 的参数写法，AI 应理解各种合法形式。

**参数格式**：
- 必须使用 git log 风格（`-5`、`--grep "xxx"` 等），参数名前加 `-` 或 `--`
- AI 应理解等价形式：
  - **限制数量**：`-5`、`-n 5`、`--limit 5`
  - **关键词过滤**：`--grep "xxx"`、`-g "xxx"`
- 参数可以组合使用（如 `-10 --grep "xxx"`）

**过滤规则**：
- `topic ls` - 按话题名称过滤
- `qa ls` - 按问答内容（用户输入或 AI 响应）过滤
- `snap ls` - 按快照名称过滤
- `conv ls` - 按对话名称过滤
- `mem ls` - 按记忆的键或值过滤

**示例**：
```bash
tt topic ls -5              # 显示最近 5 个话题
tt qa ls --grep "装饰器"     # 显示包含"装饰器"的问答
tt snap ls -10 --grep "阶段"  # 显示最近 10 个包含"阶段"的快照
```

## 输出格式规则

### ls 命令 - 树状图

所有 `ls` 命令使用树状图格式，不包含统计信息：

```
**{对象类型}列表**
📍 当前：{当前对象格式}
📊 共 {数量} 个{对象类型}

📁 {对象 1 格式}
├── {子对象 1 格式}
└── {子对象 2 格式}
```

### show 命令 - 详情

**规则**：只有被查询的对象是最后一个层级、没有子层级时，才比 ls 详细；否则和 ls 一样。

| 命令 | 是否有子层级 | 是否比 ls 详细 | 显示内容 |
|------|-------------|---------------|---------|
| `tt conv show` | ✅ 有 | ❌ 否 | 同 ls |
| `tt topic show` | ✅ 有 | ❌ 否 | 同 ls |
| `tt snap show` | ✅ 有 | ❌ 否 | 同 ls |
| `tt mem show` | ❌ 无 | ✅ 是 | 显示键值对原文 |
| `tt qa show` | ❌ 无 | ✅ 是 | 显示概要，不显示原文 |

## 统一格式规范

### 对象格式

| 对象 | 格式 |
|------|------|
| **对话** | `conv_{id}: {名称} \| {话题数}话题 {快照数}快照 {记忆数}记忆` |
| **话题** | `topic_{id}: {名称} \| {问答数}问答` |
| **问答** | `conv_{id}/topic_{id}/qa_{id} \| {摘要}` |
| **快照** | `snap_{id}: {名称} \| {所属对话}` |
| **记忆** | `mem_{id}: {名称} \| {键值对数}键值对 \| {所属对话}` |

### 分隔符规则

- `:` 用于分隔 ID 和名称（名称是对象的属性）
- `\|` 用于分隔 ID 和摘要/统计信息（摘要不是对象的属性）

### 标记说明

- `💾` 表示新创建/保存的对象
- `📎` 表示被引用/继承的对象
- `📍` 表示当前激活的对象（仅 ls 命令）

## 命令响应格式

### 创建操作（new/save）

```
AI: ✅ 已创建/保存{对象类型}
💾 {对象格式}
```

### 切换/使用操作（use）

```
AI: ✅ 已使用{对象类型}
📎 {被引用对象格式}
💾 {新创建对象格式}（如有）
```

### 删除操作（rm）

```
AI: ✅ 已删除{对象类型}
📎 {对象格式}
```

## 与其他规则的配合

- 本规则配合各具体规则文件使用
- 具体规则文件（如 `talktree-topic-management.md`）只需引用本规则，无需重复说明
- 具体规则文件专注于特定对象的业务逻辑
