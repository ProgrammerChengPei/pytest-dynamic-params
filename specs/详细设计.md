### 2.2 数据流设计

#### 2.2.1 参数化流程

1. **装饰器应用**：用户使用 `@parametrize_fixture` 装饰器标记 fixture，或使用 `@param_generator` 创建链式依赖参数生成器
2. **参数解析**：装饰器解析参数名称和值，注册参数化配置
3. **依赖处理**：`dependency/resolver.py` 解析链式依赖关系和其他依赖关系
4. **生成器执行**：如果使用了 `@param_generator`，`generator/base.py` 执行生成器函数生成参数，支持A→B→C的链式依赖传递
5. **参数组合**：`parametrize/combinator.py` 组合多个参数化装饰器的参数
6. **与 pytest 集成**：`plugin/hooks.py` 将处理后的参数传递给 pytest 的参数化机制
7. **测试执行**：pytest 执行测试函数，使用生成的参数

#### 2.2.2 生成器执行流程

1. **生成器定义**：用户使用 `@param_generator` 装饰器定义生成器函数
2. **注册生成器**：生成器被注册到 `generator/registry.py` 中的注册中心
3. **缓存检查**：`generator/cache.py` 检查是否启用了缓存，如果启用且缓存命中，直接返回缓存值
4. **懒加载检查**：`generator/lazy.py` 检查是否启用了懒加载，如果启用，延迟执行
5. **生成器执行**：执行生成器函数，生成参数值
6. **缓存存储**：如果启用了缓存，将生成的参数值存储到缓存中
7. **返回结果**：返回生成的参数值

### 4.2 自动预加载机制

**触发条件**：

**实现流程**：
```python

    self.scope = scope
    self._register_with_manager()

# 3. SyncManager 检测 scope 并预加载
def register_generator(self, generator):
    if self.config['is_master'] and generator.scope in ('session', 'module'):
        self._preload_generator(generator)

# 4. 写入同步文件
def _preload_generator(self, generator):
    data = generator._execute_func()
    generator.set_preloaded_data(data)
    self._write_sync_file()
```

### 4.3 文件同步机制

**同步文件内容**：
```json
{
  "generators": {
    "generate_users": {
      "data": [...],  // 预加载的数据
      "scope": "session",
      "cache": true
    }
  }
}
```

**原子写入**：
```python
def _write_sync_file(self) -> None:
    # 1. 写入临时文件
    temp_file = self.sync_file.with_suffix('.tmp')
    with open(temp_file, 'w') as f:
        json.dump(sync_data, f)
    
    # 2. 原子重命名（避免并发读取问题）
    temp_file.replace(self.sync_file)
```

**Worker 读取**：
```python
def load_from_sync_file(self) -> bool:
    with open(self.sync_file, 'r') as f:
        data = json.load(f)
    
    for name, gen_data in data['generators'].items():
        if name in self.generators:
            self.generators[name].set_preloaded_data(gen_data['data'])
```

def pytest_configure(config):

from dynamic_params import param_generator

def generate_realtime_orders():

### 4.6 性能优化

**优化策略**：
1. **大数据走文件** - 避免 pytest 钩子序列化限制
2. **小配置走钩子** - 快速高效
3. **原子写入** - 避免并发冲突
4. **连接池复用** - 避免重复创建连接

**性能对比**：

| 场景 | 传统方式 | 同步方案 | 提升 |
|------|---------|---------|------|
| 数据库连接数 | N 个（每 worker） | 1 个（主进程）+ N 个（按需） | 减少 80% |
| API 调用次数 | N 次（每 worker） | 1 次（主进程） | 减少 90% |
| 数据一致性 | ❌ 可能不一致 | ✅ 完全一致 | 100% |

### 4.7 最佳实践

**✅ 推荐**：
```python
# 1. Session scope 用于静态数据
@param_generator(scope='session')
def static_data():
    ...

# 2. Function scope 用于实时数据
@param_generator(scope='function')
def realtime_data():
    ...

# 3. 使用连接池管理数据库连接
with WorkerPool.get_connection('db', create_func) as conn:
    ...

# 4. 预加载时脱敏敏感数据
return {'id': user.id}  # 不包含 password
```

**❌ 避免**：
```python
# 1. 预加载超大数据
return list(range(10_000_000))

# 2. 预加载实时变化数据
return get_realtime_data()

# 3. 返回连接对象
return database.connect()
```
