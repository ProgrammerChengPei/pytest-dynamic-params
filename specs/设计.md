# pytest 动态参数化系统设计文档

## 1. 系统概述

### 1.1 设计目标

本设计文档详细描述了 pytest-dynamic-params 插件的技术架构和实现方案，聚焦于如何通过技术手段解决传统 pytest 参数化机制的局限性，实现更强大、更灵活的动态参数化能力。

**技术设计目标**：
1. **模块化架构**：构建清晰的分层架构，确保系统可维护性和可扩展性
2. **高性能实现**：通过懒加载、缓存和增量生成等技术优化性能
3. **可靠的依赖管理**：实现精确的参数依赖解析和执行顺序控制
4. **无缝集成**：与 pytest 现有机制深度集成，保持兼容性
5. **可测试设计**：模块化设计便于单元测试和集成测试

### 1.2 设计原则

- **单一职责**：每个模块专注于特定功能，避免职责混合
- **开闭原则**：系统设计支持扩展，避免对现有代码的修改
- **依赖倒置**：高层模块依赖抽象接口，不依赖具体实现
- **接口隔离**：提供细粒度接口，减少模块间耦合
- **性能优先**：设计考虑性能因素，特别是在处理大规模参数组合时

### 1.3 核心概念与技术术语

- **参数生成器**：使用 `@generator` 装饰器标记的函数，负责生成参数值
- **动态参数**：在运行时生成的参数，可依赖其他参数或 fixture
- **依赖关系**：参数之间的依赖链，需按正确顺序处理
- **懒加载**：推迟参数生成到实际需要时，减少不必要的计算
- **增量生成**：只重新生成受影响的参数，提高性能
- **拓扑排序**：用于解析参数依赖顺序的算法
- **DynRef**：动态引用类，用于在参数化中引用其他参数和 fixture

## 2. 架构设计

### 2.1 整体架构

**架构层次**：
```
┌─────────────────────────────────────────────────────────────────────┐
│  用户层                                                             │
│  ├── 测试用例 (使用@use_generators装饰器)                          │

├─────────────────────────────────────────────────────────────────────┤
│  核心层                                                             │
│  ├── 生成器注册表 (GeneratorRegistry) - 单例模式管理生成器         │
│  ├── 依赖解析器 (DependencyResolver) - 拓扑排序算法               │

│  ├── 作用域管理器 (ScopeManager) - 生命周期管理                   │
│  ├── 缓存管理器 (CacheManager) - 多级缓存策略                     │

└─────────────────────────────────────────────────────────────────────┘
```

**数据流**：
1. **注册阶段**：用户定义参数生成器和测试用例
2. **收集阶段**：pytest 收集测试，插件解析装饰器和依赖关系
3. **生成阶段**：按依赖顺序执行参数生成器，处理懒加载
4. **执行阶段**：解析 DynRef 引用，执行测试函数
5. **清理阶段**：根据作用域清理资源和缓存

### 2.2 核心组件设计

#### 2.2.1 生成器注册表 (GeneratorRegistry)

**技术实现**：
- **单例模式**：确保全局唯一实例，使用 `__new__` 方法实现
- **线程安全**：使用线程锁保护注册和访问操作
- **内存优化**：弱引用存储，避免内存泄漏

**关键方法**：
- `register(generator_func, param_name)`：注册参数生成器
- `get_generator(param_name)`：获取参数对应的生成器
- `clear_cache(scope)`：按作用域清理缓存

#### 2.2.2 依赖解析器 (DependencyResolver)

**技术实现**：
- **拓扑排序**：使用 Kahn 算法实现依赖解析
- **循环依赖检测**：通过入度计算和遍历检测
- **依赖图构建**：从生成器函数签名提取依赖关系

**关键方法**：
- `resolve_order(generators)`：解析生成器执行顺序
- `detect_cycles(generators)`：检测循环依赖
- `get_dependency_graph(generators)`：构建依赖图

#### 2.2.3 参数组合引擎 (CombinationGenerator)

**技术实现**：
- **组合生成**：使用笛卡尔积算法生成参数组合
- **懒加载支持**：创建 LazyResult 占位符
- **内存优化**：延迟生成，避免一次性创建所有组合

**关键方法**：
- `generate_combinations(param_dict)`：生成参数组合
- `generate_lazy_combinations(static_params, lazy_generators)`：生成懒加载组合
- `filter_combinations(combinations, condition)`：过滤参数组合

#### 2.2.4 作用域管理器 (ScopeManager)

**技术实现**：
- **作用域层次**：实现 function < class < module < session 的层次结构
- **资源管理**：跟踪每个作用域的资源，在作用域结束时清理
- **作用域继承**：支持作用域嵌套和继承

**关键方法**：
- `get_scope(scope_name)`：获取作用域实例
- `enter_scope(scope_name)`：进入作用域
- `exit_scope(scope_name)`：退出作用域并清理资源

#### 2.2.5 缓存管理器 (CacheManager)

**技术实现**：
- **多级缓存**：按作用域实现不同级别的缓存
- **缓存键生成**：基于参数值和上下文生成唯一缓存键
- **缓存清理**：实现 LRU 策略自动清理过期缓存

**关键方法**：
- `get(key, scope)`：获取缓存值
- `set(key, value, scope)`：设置缓存值
- `clear(scope)`：清理指定作用域的缓存
- `get_stats()`：获取缓存统计信息

## 4. 关键算法

### 4.1 依赖解析算法

**拓扑排序算法（Kahn 算法）**：

**算法描述**：
1. **依赖图构建**：从每个参数生成器的函数签名提取依赖关系，构建有向图
2. **入度计算**：统计每个节点的依赖数量（入度）
3. **拓扑排序**：使用队列处理入度为0的节点，逐步减少依赖节点的入度
4. **循环依赖检测**：通过检查处理节点数量与总节点数量是否一致

**伪代码**：
```python
def resolve_dependency_order(generators):
    # 构建依赖图
    graph = {gen.param_name: gen.dependencies for gen in generators}
    
    # 计算入度
    in_degree = {name: 0 for name in graph}
    for deps in graph.values():
        for dep in deps:
            if dep in in_degree:
                in_degree[dep] += 1
    
    # 拓扑排序
    queue = [name for name, deg in in_degree.items() if deg == 0]
    result = []
    
    while queue:
        name = queue.pop(0)
        result.append(get_generator_by_name(name))
        
        for dep in graph.get(name, []):
            in_degree[dep] -= 1
            if in_degree[dep] == 0:
                queue.append(dep)
    
    # 检查循环依赖
    if len(result) != len(generators):
        raise CircularDependencyError(generators)
    
    return result
```

### 4.2 懒加载组合生成算法

**算法描述**：
1. **参数分类**：分离静态参数和动态参数
2. **静态组合**：生成静态参数的笛卡尔积组合
3. **懒加载包装**：为每个静态组合创建懒加载结果占位符
4. **内存优化**：避免一次性创建所有参数组合，减少内存使用

**伪代码**：
```python
def generate_lazy_combinations(static_params, lazy_generators):
    # 生成立即参数的所有组合
    immediate_combinations = generate_static_combinations(static_params)
    
    # 为每个立即组合创建懒加载生成器
    all_combinations = []
    for combo in immediate_combinations:
        new_combo = combo.copy()
        
        for generator in lazy_generators:
            lazy_result = LazyResult(generator, combo)
            new_combo[generator.param_name] = lazy_result
        
        all_combinations.append(new_combo)
    
    return all_combinations
```

### 4.3 增量生成变化检测算法

**算法描述**：
1. **状态比较**：深度比较参数值的变化，识别哪些参数发生了变化
2. **依赖链分析**：使用广度优先搜索分析受影响的参数链
3. **增量更新**：只重新生成受影响的参数，减少不必要的计算

**伪代码**：
```python
def detect_affected_parameters(previous_state, current_state, dependency_graph):
    # 检测变化的参数
    changed_params = []
    for param_name, current_value in current_state.items():
        previous_value = previous_state.get(param_name)
        if not deep_equals(previous_value, current_value):
            changed_params.append(param_name)
    
    # 分析受影响的参数链
    affected = set(changed_params)
    queue = deque(changed_params)
    
    while queue:
        param = queue.popleft()
        
        # 找到直接依赖param的参数
        for dependent_param, deps in dependency_graph.items():
            if param in deps and dependent_param not in affected:
                affected.add(dependent_param)
                queue.append(dependent_param)
    
    return list(affected)
```

## 5. 接口设计

### 5.1 装饰器接口

#### 5.1.1 @generator

```python
def generator(scope="function", cache=True, lazy=True):
    """
    参数生成器装饰器
    
    Args:
        scope: 作用域，支持 function/class/module/session
        cache: 是否启用缓存
        lazy: 是否支持懒加载
    """
    def decorator(func):
        # 添加元数据
        func._is_generator = True
        func._scope = scope
        func._cache_enabled = cache
        func._lazy_support = lazy
        return func
    return decorator
```

#### 5.1.2 @use_generators

```python
def use_generators(**param_mapping):
    """
    使用动态参数装饰器
    
    Args:
        param_mapping: 参数名到生成器函数的映射
    """
    def decorator(test_func):
        # 验证生成器函数
        for param_name, generator_func in param_mapping.items():
            if not hasattr(generator_func, '_is_generator'):
                raise InvalidGeneratorError(f"函数 {generator_func.__name__} 不是参数生成器")
        
        # 存储映射关系
        test_func._mapping = param_mapping
        test_func._requires = True
        return test_func
    return decorator
```

#### 5.1.3 @dynamic_parametrize

```python
def dynamic_parametrize(*param_args, **param_kwargs):
    """
    动态参数化装饰器
    
    Args:
        *param_args: 与 pytest.mark.parametrize 相同的参数格式
        **param_kwargs: 与 pytest.mark.parametrize 相同的关键字参数
    """
    def decorator(test_func):
        if not hasattr(test_func, '_dynamic_parametrize'):
            test_func._dynamic_parametrize = []
        
        test_func._dynamic_parametrize.append({
            'args': param_args,
            'kwargs': param_kwargs
        })
        
        test_func._requires_dynamic_parametrize = True
        return test_func
    return decorator
```

## 6. 集成设计

### 6.1 pytest 钩子集成

#### 6.1.1 pytest_generate_tests

**职责**：集成动态参数化系统到 pytest 测试收集阶段

**执行流程**：
1. 检查测试函数是否需要动态参数
2. 收集静态参数和 fixture 信息

7. 调用 metafunc.parametrize 进行参数化

**职责**：处理测试执行阶段的动态参数

**执行流程**：
1. 检查测试函数是否使用了动态参数
2. 解析 DynRef 引用
3. 执行测试函数
4. 收集测试结果

### 6.2 Fixture 系统集成

**设计要点**：
- 为懒加载参数创建动态 fixture
- 在 fixture 中执行懒加载生成器
- 结合 pytest 的 fixture 缓存机制
- 支持 fixture 的作用域管理

**实现方案**：
```python
def create_lazy_fixture(param_name, generator):
    @pytest.fixture(scope=generator.scope)
    def lazy_fixture(request):
        # 收集执行上下文
        context = {}
        for dep in generator.dependencies:
            if hasattr(request, 'getfixturevalue'):
                try:
                    context[dep] = request.getfixturevalue(dep)
                except pytest.FixtureLookupError:
                    pass
        
        # 执行生成器
        result = generator.get_result(context)
        if isinstance(result, LazyResult):
            return result.execute()
        return result
    
    return lazy_fixture
```

## 7. 性能优化

### 7.1 懒加载机制

**优化策略**：
- 推迟参数生成到实际需要时
- 避免生成未执行的测试用例的参数
- 结合 pytest 的测试过滤功能

**实现要点**：
- 在测试收集阶段只创建懒加载对象
- 在 fixture 调用时执行生成器
- 使用占位符机制处理懒加载参数

### 7.2 缓存机制

**优化策略**：
- 缓存参数生成结果，避免重复计算
- 按作用域管理缓存
- 实现缓存大小限制和自动清理

**实现要点**：
- 使用多级缓存架构
- 生成唯一的缓存键
- 支持缓存失效和清理

### 7.3 增量生成

**优化策略**：
- 只重新生成受影响的参数
- 重用未受影响的生成结果
- 减少不必要的计算

**实现要点**：
- 检测参数状态变化
- 分析受影响的参数链
- 只执行受影响的生成器

## 8. 错误处理

### 8.1 异常体系

```
DynamicParamError (基础异常)
  ├── MissingParameterError
  ├── CircularDependencyError
  ├── InvalidGeneratorError
  ├── ConfigurationError
  └── ExecutionError
```

### 8.2 错误处理策略

- **验证阶段错误**：在测试收集阶段捕获，提供详细的错误信息
- **执行阶段错误**：在测试执行阶段捕获，包装为 ExecutionError
- **配置错误**：在系统初始化时捕获，使用默认值并记录警告

### 8.3 错误信息设计

- **MissingParameterError**：包含缺失的参数名称、生成器函数名称、可用参数列表
- **CircularDependencyError**：包含完整的依赖链
- **ExecutionError**：包含生成器函数名称、异常类型和消息、调用参数、堆栈跟踪
