# pytest-dynamic-params 插件需求文档

## 1. 项目概述
pytest-dynamic-params 是一个为 pytest 提供动态参数生成和参数化能力的插件，旨在解决 `pytest.mark.parametrize` 的局限性，让测试参数化更灵活、更强大。

### 1.1 核心价值
- 提供动态参数生成能力，支持复杂的参数生成逻辑
- 扩展参数化范围，支持对测试函数、fixture 和生成器进行参数化
- 支持参数间的依赖关系，通过 DynRef 实现参数引用
- 与 pytest 原生功能完全兼容，无缝集成

## 2. 功能需求

### 2.1 动态参数生成
- **需求ID**: F001
- **功能描述**: 使用生成器函数动态生成测试参数，支持复杂的参数生成逻辑
- **详细说明**: 
  - 提供 `@param_generator` 装饰器，用于定义参数生成函数
  - 生成器函数可以包含任意复杂的逻辑来生成参数
  - 生成器函数可以返回任何可迭代的数据类型
  - 支持生成器的缓存和懒加载功能

### 2.2 扩展参数化
- **需求ID**: F002
- **功能描述**: 扩展参数化范围，支持对测试函数、fixture 和生成器进行参数化
- **详细说明**: 
  - 提供 `@parametrize_test` 装饰器，用于对测试函数进行参数化
  - 提供 `@parametrize_fixture` 装饰器，用于对 fixture 进行参数化
  - 提供 `@parametrize_generator` 装饰器，用于对生成器进行参数化
  - 支持在参数化中使用直接数值、fixture、其他生成器等作为参数来源

### 2.3 参数依赖
- **需求ID**: F003
- **功能描述**: 支持参数间的依赖关系，通过 DynRef 实现参数引用
- **详细说明**: 
  - 提供 `DynRef` 类，用于在参数化中引用其他参数
  - 支持引用 fixture、生成器 的值
  - 支持在参数化中使用复杂表达式

### 2.4 与 pytest 原生集成
- **需求ID**: F004
- **功能描述**: 与 pytest 原生功能完全兼容，无缝集成
- **详细说明**: 
  - 与 `pytest.mark.parametrize` 完全兼容，可以混合使用
  - 遵循 pytest 的设计理念和使用方式
  - 支持 pytest 的 fixture 机制

### 2.5 缓存策略
- **需求ID**: F005
- **功能描述**: 生成器支持缓存，提高性能
- **详细说明**: 
  - 支持不同作用域的缓存（function、class、module、session）
  - 可以通过 `cache` 参数启用或禁用缓存

### 2.6 懒加载
- **需求ID**: F006
- **功能描述**: 生成器支持懒加载，按需生成数据
- **详细说明**: 
  - 可以通过 `lazy` 参数启用懒加载
  - 懒加载的生成器只有在需要时才会执行

## 3. 非功能需求

### 3.1 性能要求
- **需求ID**: NF001

## 5. 范围限定

### 5.1 支持的 Python 版本
- 支持 Python 3.7+

### 5.2 支持的 pytest 版本
- 支持 pytest 7.0+

### 5.3 不支持的功能
- 不支持在非测试函数上使用 `pytest.mark.parametrize`（遵循 pytest 9.0+ 的限制）
